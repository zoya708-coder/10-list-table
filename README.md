# Python: Списки та Матриці (10 клас) 🚀

Інтерактивний навчальний веб-сайт з інформатики для учнів 10 класу.

## 📖 Наповнення проєкту:
1. **Теорія:** Одновимірні списки, індексація, методи, двовимірні матриці.
2. **STEM-Завдання:** Аналіз температурного режиму Smart-Теплиці з можливістю тестування коду.
3. **Тестування:** Інтерактивна перевірка знань.

## 🛠 Публікація на GitHub Pages:
1. Розархівуйте цей файл.
2. Створіть новий репозиторій на GitHub.
3. Завантажте файл `index.html` та `README.md`.
4. Перейдіть у **Settings -> Pages** та оберіть `Branch: main` -> **Save**.
