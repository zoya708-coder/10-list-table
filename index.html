Від баз даних до двовимірних матриць

Дізнайтеся, як зберігати, обробляти та аналізувати впорядковані колекції даних у Python: від одновимірних списків-потягів до двовимірних матриць-будинків.

1

Що таке список (List)?

Список — це впорядкований контейнер для зберігання послідовності об'єктів під одним іменем.

  • Квадратні дужки: Синтаксис [1, 2, 3]
  • Різні типи даних: Числа, рядки, дроби в одному списку
  • Змінюваність: Елементи можна редагувати після створення
# Приклад створення списку
data = [5, 'Кіт', 3.14]
2

Три шляхи створення списку

a = [] # 1. Порожній список
nums = [5, 10, 15] # 2. Із готовими даними
a = [i for i in range(5)] # 3. Генератором (ListComp)

Генератори списків дозволяють створювати нові масиви усього в один рядок коду!

3

Анатомія списку: Індекси

Важливо! Індексація завжди починається з нуля (0). Перший елемент — це index 0. Від'ємні індекси відраховують з кінця (-1).

animals = ['Кіт', 'Собака', 'Миша', 'Хом'як']

# Індекси: 0 1 2 3

# Вд'ємні: -4 -3 -2 -1

print(animals[0]) # Виведе: Кіт

print(animals[-1]) # Виведе: Хом'як

print(len(animals)) # Довжина: 4

4

Основні методи та функції

.append(x) — додати в кінець
.pop(i) — вилучити за індексом
.remove(x) — вилучити за значенням
.clear() — очистити список
Функції над списками:
  • sum(a) — сума елементів
  • min(a) / max(a) — найменше/найбільше
  • sorted(a) — відсортований новий список
5

Двовимірні масиви (Матриці / Таблиці)

У Python немає окремого типу даних «матриця». Таблиця реалізується як список списків (List of Lists).

# Створення таблиці 2х3 (2 рядки, 3 стовпчики):

table = [

[1, 7, 17], # рядок 0

[8, 18, 19] # рядок 1

]

# Звернення: table[ряд][стовпчик]

print(table[1][2]) # Отримаємо 19

// Обхід двовимірної таблиці вкладеними циклами:

for row in table:

for cell in row:

print(cell, end=' ')

print() # Перехід на новий рядок
